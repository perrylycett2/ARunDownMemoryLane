# A Run Down Memory Lane

A small browser arcade runner where you collect glowing memories while jumping over potholes and traffic cones.

## Play locally

```bash
npm run serve
```

Then open <http://localhost:8080> in a browser.

## Controls

- **Space** or **Up Arrow**: jump / start
- **P**: pause or resume
- **R**: restart

## Checks

```bash
npm test
node --check src/game.js && node --check src/gameCore.js
```
